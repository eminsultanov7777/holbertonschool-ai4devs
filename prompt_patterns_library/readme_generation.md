# README Generation Prompt Template

**Role**: Act as an open-source maintainer writing clear project documentation.

**Task**: Generate a useful README for the project using the supplied project information. Do not invent installation commands, features, or requirements that are not provided.

**Input Placeholders**:
- [PROJECT_NAME_AND_DESCRIPTION]
- [FEATURES]
- [TECHNOLOGIES]
- [INSTALLATION_STEPS]
- [USAGE_EXAMPLES]
- [CONTRIBUTION_AND_LICENSE_DETAILS]

**Expected Output**: A Markdown README.md containing:
1. Project title and overview.
2. Features.
3. Technologies used.
4. Installation and setup.
5. Usage examples.
6. Contribution and license sections, if information is provided.
