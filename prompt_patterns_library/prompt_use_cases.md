# Prompt Use Cases

This document describes common situations where reusable AI prompt patterns can improve software development workflows.

## 1. Code Quality

### 1.1 Code Refactoring
- **Goal**: Improve code readability, structure, and maintainability.
- **Input**: Source code in [LANGUAGE].
- **Output**: Refactored code with an explanation of the improvements.

### 1.2 Code Optimization
- **Goal**: Improve code performance and reduce unnecessary operations.
- **Input**: A function or code block in [LANGUAGE].
- **Output**: Optimized code with an explanation of performance improvements.

### 1.3 Style Enforcement
- **Goal**: Ensure consistent coding style and naming conventions.
- **Input**: Source code and coding style guidelines.
- **Output**: Updated code following the specified conventions.

## 2. Debugging

### 2.1 Error Analysis
- **Goal**: Identify the cause of programming errors.
- **Input**: Error message, stack trace, and relevant source code.
- **Output**: Explanation of the error and possible solutions.

### 2.2 Bug Fixing
- **Goal**: Find and fix logical errors in existing code.
- **Input**: Code containing a bug and its expected behavior.
- **Output**: Corrected code with an explanation of the changes.

### 2.3 Code Troubleshooting
- **Goal**: Investigate unexpected program behavior.
- **Input**: Code, observed behavior, and expected behavior.
- **Output**: Possible causes and step-by-step troubleshooting instructions.

## 3. Documentation

### 3.1 Code Documentation
- **Goal**: Generate clear documentation for functions and classes.
- **Input**: Source code in [LANGUAGE].
- **Output**: Documentation describing parameters, return values, and functionality.

### 3.2 README Generation
- **Goal**: Create a clear README file for a software project.
- **Input**: Project description, technologies, installation steps, and usage instructions.
- **Output**: A structured README.md file.

### 3.3 Technical Explanation
- **Goal**: Explain complex technical concepts in simple language.
- **Input**: A technical topic or code snippet.
- **Output**: A structured explanation with examples.

## 4. Testing

### 4.1 Unit Test Generation
- **Goal**: Generate unit tests for individual functions.
- **Input**: Source code and expected function behavior.
- **Output**: Unit tests covering normal and edge cases.

### 4.2 Test Case Design
- **Goal**: Identify different scenarios for testing an application.
- **Input**: Feature description and functional requirements.
- **Output**: A list of positive, negative, and boundary test cases.

### 4.3 Test Failure Analysis
- **Goal**: Understand why automated tests are failing.
- **Input**: Test code, failure messages, and application code.
- **Output**: Explanation of the failure and suggested corrections.

---

## Conclusion

These 12 use cases demonstrate how reusable AI prompt patterns can support different stages of software development, including code quality improvement, debugging, documentation, and testing.
