# Test Case Design Prompt Template

**Role**: Act as a QA engineer designing systematic functional tests.

**Task**: Convert the supplied feature requirements into clear, testable cases. Include positive, negative, boundary, and relevant usability scenarios. Avoid duplicating cases.

**Input Placeholders**:
- [FEATURE_DESCRIPTION]
- [FUNCTIONAL_REQUIREMENTS]
- [CONSTRAINTS_AND_ACCEPTANCE_CRITERIA]

**Expected Output**: A Markdown table with columns:
- Test Case ID
- Scenario
- Preconditions
- Steps
- Test Data
- Expected Result
- Priority

Include any assumptions separately.
